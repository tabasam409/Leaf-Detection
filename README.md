# 🌿 Leaf Detection using Deep Learning

## Description
A deep learning-based image classification project that detects and identifies different types of leaves/plants from images. This project uses Convolutional Neural Networks (CNN) for accurate plant leaf recognition.

## Technologies Used
- Python
- TensorFlow / Keras
- OpenCV
- NumPy
- Matplotlib
- Jupyter Notebook

## How to Run
1. Clone the repository:
   ```
   git clone https://github.com/tabasam409/Leaf-Detection.git
   cd Leaf-Detection
   ```
2. Install dependencies:
   ```
   pip install tensorflow opencv-python numpy matplotlib jupyter
   ```
3. Open the notebook:
   ```
   jupyter notebook Leaf_Detection.ipynb
   ```

## Project Structure
- `Leaf_Detection.ipynb` - Main notebook with model training and detection code
